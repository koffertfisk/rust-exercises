# Rust Learning Exercises

This repository contains a set of progressively challenging Rust exercises.
Each exercise is self-contained in its own binary crate.

## Structure

- **ex01_hello_world** – Simple "Hello, World!" starter
- **ex02_calculator** – Basic CLI calculator with operator parsing
- **ex03_guessing_game** – Number guessing game using RNG and control flow
- ...

## Running an Exercise

```bash
cd exercises/ex06_traffic_light
cargo run
```
or build all:
```bash
cargo build --workspace
```
